# Example Markdown File

This is a sample markdown file. See below for formatting possibilities.

## Headings

You can create headings of different levels by using `#` before the text.

## Bold

To make text bold, just put two asterisks `**` before and after the text, like this: **bold**.

## Italic

To make text italic, just put one asterisk `*` before and after the text, like this: *italic*.

## Links

To create a link, put the link text in square brackets `[]` and the URL in parentheses `()`, like this: [link](https://www.google.com).

## Images

To add an image, put an exclamation mark `!`, the alt text in square brackets `[]`, and the image URL in parentheses `()`, like this: ![alt text](https://www.google.com/images/branding/googlelogo/1x/googlelogo_color_272x92dp.png).

## Lists

You can create ordered and unordered lists. For unordered lists, put an asterisk `*` before the text. For ordered lists, put the number followed by a period `1.` before the text. See below:

* Item 1
* Item 2
* Item 3

1. Item 1
2. Item 2
3. Item 3

## Code

To add a code block, put three backticks ``` before and after the code, like this:

```python
print('Hello, world!')
```

```html
<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <p>Sample page</p>
</body>
</html>
```

```css
body {
    background-color: lightblue;
}
```

```javascript
document.getElementById('demo').innerHTML = 'Hello, world!';
```

```markdown
This is a markdown code block.

## Headings

You can create headings of different levels by using `#` before the text.

...
```

To add inline code, just put a backtick \` before and after the code, like this: `code`.

## Internal Links

To create internal links, just put a hash `#` before the text, like this: [#Headings](#headings).

## Footnotes

To add footnotes, just put a caret `^` before the text, like this:

This is a footnote example[^1].

[^1]: This is the footnote.

## Abbreviations

To add abbreviations, put the meaning in square brackets `[]` and the abbreviation in parentheses `()`, like this: HTML, hover over HTML.

*[HTML]: Hyper Text Markup Language
*[W3C]:  World Wide Web Consortium

See the code above to see the result.

```markdown

```

## Blockquote

To add a blockquote, just put a greater-than sign `>` before the text, like this:

> This is a blockquote example.

## Horizontal Line

To add a horizontal line, just put three hyphens `---` on a line, like this:

---

## Tables

To create a table, separate columns with vertical bars `|` and add hyphens `-` below the header, like this:

| Header 1   | Header 2   | Header 3   |
|------------|------------|------------|
| Row 1      | Row 1      | Row 1      |
| Row 2      | Row 2      | Row 2      |
| Row 3      | Row 3      | Row 3      |

## Comments

To add comments, just put a semicolon `;` before the text, like this:

; This is a comment

## References

To add references, just put an at sign `@` before the text, like this:

@guisaldanha
